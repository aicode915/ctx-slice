# Contributing to ctx-slice

Thank you for considering contributing to `ctx-slice`!

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/ctx-slice.git
   cd ctx-slice
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Build and watch:
   ```bash
   npm run build
   # or watch mode
   npm run dev
   ```

4. Run tests:
   ```bash
   npm test
   ```

## Pull Request Guidelines

- Ensure all existing unit and E2E tests pass (`npm test`).
- Add tests for any new features or bug fixes.
- Keep dependencies minimal to maintain fast installation and lightweight runtime.
